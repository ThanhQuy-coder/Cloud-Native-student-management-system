
  # Deploy

  This is a code bundle for Deploy. The original project is available at https://www.figma.com/design/yRIW74OKf1izmfiih930le/Deploy.

  ## Running the code

  1. Run `npm install` to install the dependencies.
  2. Run `npm run dev` or `npm start` to start the development server.

  To preview the production build locally:

  1. Run `npm run build`
  2. Run `npm run preview`
